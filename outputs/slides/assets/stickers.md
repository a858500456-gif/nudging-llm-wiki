# 圖貼情緒對照表

Stage 2 選圖貼時查這張表（AGENTS.md §7.5、Check 2-4）。規則：
- 表情要符合這一頁的內容情緒
- 相鄰兩頁不重複使用同一個圖貼檔案
- 每頁 1–4 個圖貼；`器官` 系列不使用

## 角色
| 角色 | 資料夾／檔名前綴 | 適合的角色定位 |
|---|---|---|
| 小湯圓 | `tangyuan/tangyuan_` | 主角：讀者、受試者、使用者 |
| 書蟲 | `friends/bookworm_` | 講解研究、方法、數據 |
| 布丁熊 | `friends/pudding_bear_` | 反思、限制、務實的提醒 |
| 棉花雲 | `friends/cotton_cloud_` | 想像、延伸、感受 |
| 年糕貓 | `friends/niangao_cat_` | 好奇、冒險、新點子 |

## 表情 → 適用情境
| 表情 | 檔名後綴 | 適用情境 |
|---|---|---|
| 揮手 | `wave`（只有小湯圓） | 開場、打招呼 |
| 開心 | `happy` | 一般正面說明、好消息 |
| 振奮 | `cheer`（只有小湯圓） | 好結果、成功、挑戰型的正面感受 |
| 喜愛 | `love` | 推薦、溫柔的提醒、結論 |
| 思考 | `thinking` | 提出問題、研究問題、反思 |
| 驚訝 | `surprised` | 意外的發現、數據驗證 |
| 流汗 | `sweat` | 困擾、混亂、壓力大 |
| 生氣 | `angry` | 阻礙、被擋路、挫折 |
| 難過 | `sad` | 放棄、失敗、反面觀點 |
| 想睡 | `sleepy` | 無聊、資訊過載後的疲憊 |
| 生病 | `sick` | 倦怠、健康問題 |
| 口罩 | `mask` | 保護、防範、限制條件 |
