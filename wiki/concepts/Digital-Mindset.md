# Digital Mindset

> 個人對數位化累積的知識與經驗所形成的一組 cognitive schemas（思考模式），會影響他如何感知、解讀和回應與數位科技有關的情境（[[Valta2026-Technostress-Nudges]] §2.3, p.4，依據 Hildebrandt & Beimborn 2024）。

## 定義與符號
- **Mindset**：由累積的經驗形成的 cognitive schemas。遇到刺激時，對應的 schema 會被啟動，引導注意力、推論缺少的資訊、影響評價，所以也可能導致 confirmation bias（[[Valta2026-Technostress-Nudges]] §2.3, p.4）。
- **四個維度**（Hildebrandt & Beimborn 2024；[[Valta2026-Technostress-Nudges]] Table 1, p.4）：

| Thinking pattern | 說明 |
|---|---|
| Generative thinking | 持續用抽象化和模組化的方式思考，重新運用 (repurpose) 既有的解法；把數位科技看成有彈性、可以延伸的東西 |
| Data-driven thinking | 持續看見資料的潛力，把資料納入決策或產品開發 |
| Combinatorial thinking | 把數位科技可以互相組合的特性用在找解法上，擴大解法空間 |
| Risk-affine thinking | 對數位科技願意承擔經過計算的風險 |

- 在 [[Valta2026-Technostress-Nudges]] 中被建模成 **reflective second-order construct**，四個維度的 loading 介於 0.787–0.882（Fig. 5）。量表共 14 題，α = 0.734。

## 和相鄰構念的差別
（[[Valta2026-Technostress-Nudges]] §2.3, p.4–5）

| 構念 | 捕捉的是什麼 |
|---|---|
| Digital literacy | 能做什麼：操作工具、處理數位資訊的功能性技能 |
| IT self-efficacy | 相信自己能做什麼：完成 IT 任務的信心 |
| Personal innovativeness with IT | 傾向：嘗試新科技的意願（比較接近穩定的特質） |
| **Digital mindset** | **如何理解數位世界的複雜性**：schema 和 sensemaking 的框架 |

- 作者認為它是**可以改變的**，所以組織可以透過訓練來提升（[[Valta2026-Technostress-Nudges]] §6.3, p.13）。

## 在 technostress 研究中的角色
- **調節變數**：digital mindset 越高，[[Digital-Nudging|interface nudge]] 降低 hindrance [[Technostress]] 的效果越大（default × mindset $\beta = -0.278$；salience × mindset $\beta = -0.307$），但 mindset 低的人也有顯著效果（[[Valta2026-Technostress-Nudges]] §5.3）。
- **探索性結果**：調節效果主要來自 generative 和 combinatorial thinking；data-driven 和 risk-affine thinking 不顯著（[[Valta2026-Technostress-Nudges]] Table 8）。
- **作者的機制解釋**：mindset 高的人看到更大的行動和資訊空間 → 想比較的東西更多 → nudge 幫他們省下的 effort 更多。作者稱之為 "decision space optimization"。另一種相反的解釋見 [[Who-Benefits-More-From-Interface-Nudges]]。

> [!note] 推論：四個維度和 HTS 都呈正相關（r = 0.218–0.430，[[Valta2026-Technostress-Nudges]] Table 7），代表 mindset 高的人在沒有介入時反而感受到更多 hindrance。這可以支持「看到更大的決策空間」的說法，但也可能是其他原因造成的。
